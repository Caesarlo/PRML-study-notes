    1.1 多项式曲线拟合¶

    问题设置¶

    从函数 \(\sin(2\pi x)\) 上采样 \(N=10\) 个点，加入高斯噪声作为训练集：

    \[ t_n = \sin(2\pi x_n) + \epsilon, \quad \epsilon \sim \mathcal{N}(0, \sigma^2) \]
    • 输入：\(x_n \in [0, 1]\)，均匀采样
    • 目标：给定新的 \(x\)，预测对应的 \(t\)，但不知道真实的 \(\sin(2\pi x)\)

    这是一个回归问题，也是理解过拟合、模型选择、正则化的最直观例子。

    多项式模型¶

    用 \(M\) 阶多项式拟合数据：

    \[ y(x, \mathbf{w}) = w_0 + w_1 x + w_2 x^2 + \cdots + w_M x^M = \sum_{j=0}^{M} w_j x^j \]
    • \(\mathbf{w} = (w_0, w_1, \ldots, w_M)^T\) 是待学习的参数向量
    • 虽然 \(y\) 对 \(x\) 是非线性的，但对 \(\mathbf{w}\) 是线性的 → 线性模型，有解析解

    误差函数：最小二乘¶

    定义平方和误差（Sum-of-Squares Error）：

    \[ E(\mathbf{w}) = \frac{1}{2} \sum_{n=1}^{N} \left[ y(x_n, \mathbf{w}) - t_n \right]^2 \]
    • 系数 \(\frac{1}{2}\) 是为了求导后形式更简洁
    • 因为 \(E(\mathbf{w})\) 是关于系数 \(\mathbf{w}\) 的二次函数，其导数关于 \(\mathbf{w}\) 是线性的，所以可以得到闭式解。严格地说，当设计矩阵 \(\mathbf{\Phi}\) 满列秩时，最小二乘解唯一；如果不满秩，则最优解可能不唯一。

    矩阵形式求解¶

    令设计矩阵（Vandermonde 矩阵）\(\mathbf{\Phi}\)，其中 \(\Phi_{nj} = x_n^j\)：

    \[ \mathbf{\Phi} = \begin{pmatrix} 1 & x_1 & x_1^2 & \cdots & x_1^M \\ 1 & x_2 & x_2^2 & \cdots & x_2^M \\ \vdots & & & & \vdots \\ 1 & x_N & x_N^2 & \cdots & x_N^M \end{pmatrix} \]

    误差最小化的解析解（正规方程）：

    \[ \mathbf{w}^* = (\mathbf{\Phi}^T \mathbf{\Phi})^{-1} \mathbf{\Phi}^T \mathbf{t} \]

    原书 1.1 只强调该问题有闭式解，并未展开矩阵形式。这里写出正规方程是为了方便和后续线性回归衔接。实际数值计算中不建议显式求逆，高阶多项式会让 Vandermonde 矩阵病态，通常使用 np.linalg.lstsq、QR 分解或 SVD 更稳定。

    评估指标：RMS 误差¶

    \[ E_{RMS} = \sqrt{\frac{2E(\mathbf{w}^*)}{N}} \]

    除以 \(N\) 便于不同大小数据集之间比较；开根号使单位与 \(t\) 一致。

    模型阶数 M 的影响（过拟合核心）¶

    \(M\) 训练误差 测试误差 现象
    0 大 大 欠拟合，只能拟合常数
    1 较大 较大 欠拟合，只能拟合直线
    3 小 小 最佳，接近真实 \(\sin(2\pi x)\)
    9 0 极大 过拟合，完美穿过所有训练点

    关键观察：\(M=9\) 时模型有 10 个参数，恰好等于训练点数，能完美插值，但泛化极差。

    \(M=9\) 时系数 \(\mathbf{w}\) 的绝对值会极其巨大（正负交替），曲线在数据点之间剧烈震荡。这是过拟合的典型信号。

    过拟合与训练集大小的关系¶

    固定 \(M=9\)，增大 \(N\)：

    • \(N=15\)：过拟合减轻
    • \(N=100\)：拟合曲线接近 \(\sin(2\pi x)\) 所示数据集的\(M=9\)次多项式拟合，使用正则化误差函数在正则化参数\(λ\)的两个取值（对应于\(ln λ = −18\)和\(ln λ = 0\)）下的结果。无正则化的情况，即\(λ=0\)（对应于\(ln λ = −∞\)）。

    结论：过拟合是模型复杂度与数据量之间的失衡。数据量越多，可以支撑越复杂的模型。

    原书给出的粗略经验是：数据点数量不应少于自适应参数数量的若干倍，例如 5 倍或 10 倍。不过原书也特别提醒，参数数量并不一定是模型复杂度的最佳度量。

    正则化：抑制过拟合¶

    在误差函数中加入惩罚项，限制参数的增长：

    \[ \tilde{E}(\mathbf{w}) = \frac{1}{2} \sum_{n=1}^{N} \left[ y(x_n, \mathbf{w}) - t_n \right]^2 + \frac{\lambda}{2} \|\mathbf{w}\|^2 \]

    其中： $$ |\mathbf{w}|^2 = \mathbf{w}^T \mathbf{w} = w_0^2 + w_1^2 + \cdots + w_M^2 $$

    常用于控制过拟合现象的一种技术是正则化，它涉及在误差函数中添加一个惩罚项，以阻止系数达到较大的值。

    • \(\lambda\)：正则化系数，控制惩罚强度
    • 这种方法在统计学中称为岭回归（Ridge Regression），在机器学习中称为权重衰减（Weight Decay）
    • 注意：原书指出，通常 \(w_0\) 可以不参与正则化，因为惩罚 \(w_0\) 会使结果依赖于目标变量原点的选择；也可以给 \(w_0\) 单独设置正则化系数

    正则化的解析解¶

    如果所有参数都参与 L2 正则化，则闭式解可以写为：

    \[ \mathbf{w}^* = (\mathbf{\Phi}^T \mathbf{\Phi} + \lambda \mathbf{I})^{-1} \mathbf{\Phi}^T \mathbf{t} \]

    如果不惩罚偏置项 \(w_0\)，可以把 \(\mathbf{I}\) 换成：

    \[ \mathbf{R} = \operatorname{diag}(0, 1, 1, \ldots, 1) \]

    对应为：

    \[ \mathbf{w}^* = (\mathbf{\Phi}^T \mathbf{\Phi} + \lambda \mathbf{R})^{-1} \mathbf{\Phi}^T \mathbf{t} \]

    \(\lambda\) 的影响（\(M=9\) 固定）¶

    这里使用 \(\ln \lambda\) 而不是直接使用 \(\lambda\)，是因为正则化强度通常要在数量级上调节。\(\lambda\) 必须是非负数，而且有效范围可能从非常接近 0 到 1、10 甚至更大；直接画 \(\lambda\) 会把很小的取值挤在一起，不容易观察变化。取自然对数后，乘法尺度被转换成加法尺度：

    \[ \ln \lambda = -18 \quad \Longleftrightarrow \quad \lambda = e^{-18} \approx 1.5 \times 10^{-8} \]

    因此 \(\ln \lambda = -\infty\) 对应 \(\lambda = 0\)，也就是没有正则化；\(\ln \lambda = 0\) 对应 \(\lambda = 1\)。这里的 \(\ln\) 只是为了更方便地展示和比较不同数量级的正则化强度。

    \(\ln \lambda\) 现象
    \(-\infty\)（无正则化） 过拟合，系数巨大
    \(-18\)（适中） 系数受控，拟合效果接近 \(M=3\)
    \(0\)（\(\lambda=1\)，过强） 欠拟合，曲线过于平滑
    参数 ln λ = −∞ ln λ = −18 ln λ = 0
    \(w_0^*\) 0.35 0.35 0.13
    \(w_1^*\) 232.37 4.74 -0.05
    \(w_2^*\) -5321.83 -0.77 -0.06
    \(w_3^*\) 48568.31 -31.97 -0.05
    \(w_4^*\) -231639.30 -3.89 -0.03
    \(w_5^*\) 640042.26 55.28 -0.02
    \(w_6^*\) -1061800.52 41.32 -0.01
    \(w_7^*\) 1042400.18 -45.95 -0.00
    \(w_8^*\) -557682.99 -91.53 0.00
    \(w_9^*\) 125201.43 72.68 0.01

    从极端情况看：

    情况 参数行为 模型行为
    \(\lambda \to 0\) 系数可以很大 容易过拟合
    适中的 \(\lambda\) 系数被控制 泛化较好
    \(\lambda \to \infty\) 系数趋近于 0 容易欠拟合
    \(M=9\) 多项式的均方根误差 (1.3) 相对于 \(ln λ\)的图

    原书 Figure 1.8 的重点是：在固定 \(M=9\) 时，\(\lambda\) 控制模型的有效复杂度，进而决定过拟合程度。也就是说，复杂度不只由多项式阶数 \(M\) 决定。

    模型选择：如何确定 M 和 λ？¶

    方法一：验证集（Validation Set / Hold-out Set）¶

    从训练数据中划分一部分作为验证集，选在验证集上误差最小的超参数。

    缺点：减少了可用训练数据。

    方法二：交叉验证（Cross-Validation）¶

    将数据分成 \(S\) 折，每次用 \(S-1\) 折训练、1 折验证，重复 \(S\) 次取平均。

    • \(S=N\)：留一交叉验证（Leave-One-Out），计算开销大

    交叉验证是对原书 1.1 中验证集思想的自然扩展；本节原文主要强调 hold-out validation，并指出这种方式会浪费宝贵的训练数据。

    补充：从 1.1 通向概率视角¶

    原书 1.1 的最后并没有完整推导概率模型，而是给出一个重要预告：

    • 最小二乘法可以看作最大似然估计（Maximum Likelihood）的一个特例
    • 过拟合可以理解为最大似然方法中的一般问题
    • 贝叶斯方法可以缓解过拟合，即使参数数量超过数据点数量也并不必然有问题

    如果假设观测噪声是高斯分布：

    \[ t_n = y(x_n, \mathbf{w}) + \epsilon_n, \quad \epsilon_n \sim \mathcal{N}(0, \beta^{-1}) \]

    则：

    \[ p(t_n \mid x_n, \mathbf{w}, \beta) = \mathcal{N}(t_n \mid y(x_n, \mathbf{w}), \beta^{-1}) \]

    最大化整个训练集的似然：

    \[ p(\mathbf{t} \mid \mathbf{x}, \mathbf{w}, \beta) = \prod_{n=1}^{N} \mathcal{N}(t_n \mid y(x_n, \mathbf{w}), \beta^{-1}) \]

    等价于最小化平方和误差。这解释了为什么平方误差在高斯噪声假设下是自然的选择。

    进一步地，后续章节会说明：L2 正则化可以从贝叶斯角度解释为给参数加零均值高斯先验：

    \[ p(\mathbf{w} \mid \alpha) = \mathcal{N}(\mathbf{w} \mid \mathbf{0}, \alpha^{-1}\mathbf{I}) \]

    此时 MAP 估计会得到类似正则化平方误差的目标函数，并且正则化强度可以理解为先验强度与噪声精度之间的相对关系：

    \[ \lambda = \frac{\alpha}{\beta} \]

    这部分是为了衔接 PRML 后续章节，不属于 1.1 原文的完整推导。

    代码示例¶

    import numpy as np
import matplotlib.pyplot as plt

# ── 1. 生成数据 ──────────────────────────────────────────────
np.random.seed(42)
N = 10
x_train = np.linspace(0, 1, N)
t_train = np.sin(2 * np.pi * x_train) + np.random.normal(0, 0.3, N)

x_test = np.linspace(0, 1, 100)
t_test = np.sin(2 * np.pi * x_test)

# ── 2. 构建 Vandermonde 设计矩阵 ─────────────────────────────
def design_matrix(x, M):
    return np.vander(x, M + 1, increasing=True)  # shape: (N, M+1)

# ── 3. 最小二乘拟合 ──────────────────────────────────────────
def fit_poly(x, t, M):
    Phi = design_matrix(x, M)
    # 理论上可写正规方程；实践中 lstsq 比显式求逆更稳定
    w = np.linalg.lstsq(Phi, t, rcond=None)[0]
    return w

# ── 4. 正则化拟合（岭回归）───────────────────────────────────
def fit_poly_regularized(x, t, M, lam):
    Phi = design_matrix(x, M)
    # w* = (ΦᵀΦ + λI)⁻¹ Φᵀ t
    A = Phi.T @ Phi + lam * np.eye(M + 1)
    b = Phi.T @ t
    w = np.linalg.solve(A, b)
    return w

# ── 5. 预测与 RMS 误差 ───────────────────────────────────────
def predict(x, w):
    M = len(w) - 1
    Phi = design_matrix(x, M)
    return Phi @ w

def rms_error(y_pred, t):
    return np.sqrt(np.mean((y_pred - t) ** 2))

# ── 6. 不同 M 的效果对比 ─────────────────────────────────────
fig, axes = plt.subplots(2, 2, figsize=(12, 8))
for ax, M in zip(axes.flat, [0, 1, 3, 9]):
    w = fit_poly(x_train, t_train, M)
    y_pred = predict(x_test, w)

    ax.scatter(x_train, t_train, color='blue', zorder=5, label='Training data')
    ax.plot(x_test, t_test, 'g-', label='sin(2πx)')
    ax.plot(x_test, y_pred, 'r-', label=f'M={M}')
    ax.set_ylim(-1.5, 1.5)
    ax.set_title(f'M = {M}  |  Train RMS = {rms_error(predict(x_train, w), t_train):.3f}')
    ax.legend(fontsize=8)
plt.tight_layout()
plt.savefig('assets/poly_fit_M_comparison.png', dpi=150)
plt.show()

# ── 7. RMS vs M ──────────────────────────────────────────────
Ms = range(0, 10)
train_errors, test_errors = [], []
for M in Ms:
    w = fit_poly(x_train, t_train, M)
    train_errors.append(rms_error(predict(x_train, w), t_train))
    test_errors.append(rms_error(predict(x_test, w), t_test))

plt.figure(figsize=(7, 4))
plt.plot(Ms, train_errors, 'bo-', label='Training')
plt.plot(Ms, test_errors, 'ro-', label='Test')
plt.xlabel('M'); plt.ylabel('RMS Error')
plt.title('RMS Error vs Polynomial Order M')
plt.legend(); plt.grid(True)
plt.savefig('assets/rms_vs_M.png', dpi=150)
plt.show()

# ── 8. 正则化效果（M=9，不同 λ）──────────────────────────────
fig, axes = plt.subplots(1, 3, figsize=(14, 4))
for ax, ln_lam in zip(axes, [-np.inf, -18, 0]):
    lam = 0 if ln_lam == -np.inf else np.exp(ln_lam)
    if lam == 0:
        w = fit_poly(x_train, t_train, M=9)
        title = 'No regularization (λ=0)'
    else:
        w = fit_poly_regularized(x_train, t_train, M=9, lam=lam)
        title = f'ln λ = {ln_lam}'

    y_pred = predict(x_test, w)
    ax.scatter(x_train, t_train, color='blue', zorder=5)
    ax.plot(x_test, t_test, 'g-', label='sin(2πx)')
    ax.plot(x_test, y_pred, 'r-', label='M=9')
    ax.set_ylim(-1.5, 1.5)
    ax.set_title(title)
    ax.legend(fontsize=8)
plt.tight_layout()
plt.savefig('assets/regularization_comparison.png', dpi=150)
plt.show()

    关键概念总结¶

    模型复杂度（M）↑  →  训练误差 ↓，测试误差先降后升（过拟合）
数据量（N）↑      →  相同 M 下过拟合减轻
正则化（λ）↑      →  系数绝对值 ↓，偏差 ↑，方差 ↓

    本节的核心矛盾：我们希望模型足够复杂以捕捉数据规律，又不希望它把噪声也记住。这个矛盾的本质是偏差-方差权衡（Bias-Variance Trade-off），将在第 3 章从贝叶斯角度给出更系统的解答。
