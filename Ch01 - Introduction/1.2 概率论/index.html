    1.2 概率论¶

    为什么需要概率论¶

    模式识别的核心挑战是不确定性（uncertainty），它来自两个方面：

    1. 测量噪声：观测值本身含噪
    2. 数据集规模有限：无法穷举所有可能

    概率论提供了一套量化和操作不确定性的一致框架。结合决策论（1.5 节），它能让我们在信息不完整或模糊的情况下做出最优预测。

    🔗 深度学习研究者为什么需要重读概率论？ 你每天都在和概率打交道，只是可能没有意识到：nn.Softmax(dim=1) 输出的是一个类别概率分布；nn.CrossEntropyLoss() 在数学上就是负对数似然；F.dropout(x, p=0.5, training=True) 本质是在做伯努利随机采样；VAE 的 latent space 被建模为高斯分布；BatchNorm 的 running mean/var 是在做运行时期望估计；weight_decay 的背后是高斯先验 + MAP 推断。PRML 的概率论章节就是把这些"日用而不知"的概念串联起来，告诉你它们来自同一个数学框架。这一节读通之后，你会发现 loss 函数的选型、正则化的调参、不确定性估计这些工程直觉背后，都有清晰的第一性原理。

    基本概念：从水果盒子例子引入¶

    我们使用一个简单的例子，即两个有颜色的盒子，每个盒子里装有水果（苹果用绿色表示，橙子用橙色表示），来介绍概率的基本概念。

    用一个经典例子来引入所有核心概念：

    • 红盒子：2 个苹果，6 个橙子 → \(p(B=r) = 4/10\)
    • 蓝盒子：3 个苹果，1 个橙子 → \(p(B=b) = 6/10\)

    随机选一个盒子，再随机取一个水果。引入两个随机变量：

    • \(B \in \{r, b\}\)：选哪个盒子
    • \(F \in \{a, o\}\)：选到哪种水果

    概率的两条基本规则¶

    推导框架¶

    考虑两个随机变量 \(X\)（取值 \(x_i\)，\(i=1,\ldots,M\)）和 \(Y\)（取值 \(y_j\)，\(j=1,\ldots,L\)）。在 \(N\) 次试验中，\(X=x_i\) 且 \(Y=y_j\) 的次数记为 \(n_{ij}\)，\(X=x_i\) 的总次数记为 \(c_i\)，\(Y=y_j\) 的总次数记为 \(r_j\)。

    联合概率（Joint Probability）：

    \[ p(X=x_i, Y=y_j) = \frac{n_{ij}}{N} \]

    边缘概率（Marginal Probability）：

    \[ p(X=x_i) = \frac{c_i}{N} \]
    \[ p(X = x_i) = \sum_{j=1}^{L} p(X = x_i, Y = y_j) \]

    条件概率（Conditional Probability）：

    \[ p(Y=y_j \mid X=x_i) = \frac{n_{ij}}{c_i} \]
    \[ \begin{aligned} p(X = x_i, Y = y_j) &= \frac{n_{ij}}{N} = \frac{n_{ij}}{c_i} \cdot \frac{c_i}{N} \\ &= p(Y = y_j \mid X = x_i)p(X = x_i) \end{aligned} \]

    两条规则¶

    \[ \boxed{ \text{求和规则（Sum Rule）:} \quad p(X) = \sum_Y p(X, Y) } \]
    \[ \boxed{ \text{乘积规则（Product Rule）:} \quad p(X, Y) = p(Y \mid X)\, p(X) } \]

    贝叶斯定理（Bayes' Theorem）¶

    由乘积规则 + 对称性 \(p(X,Y) = p(Y,X)\) 直接推出：

    \[ p(Y \mid X) = \frac{p(X \mid Y)\, p(Y)}{p(X)} \]

    其中分母可以用求和规则展开：

    \[ p(X) = \sum_Y p(X \mid Y)\, p(Y) \]

    \(p(X)\) 是归一化常数，确保 \(p(Y|X)\) 对所有 \(Y\) 之和为 1。

    水果盒子例子的完整计算¶

    一个关于两个变量X和Y的分布示意图，其中\(X\)可取9个值，\(Y\)可取2个值。左上图显示了从这两个变量的联合概率分布中抽取的 \(60\)个样本点。其余图展示了边缘分布\(p(X)\)和\(p(Y)\)的直方图估计，以及对应于左上图底行的条件分布\(p(X|Y=1)\)。

    已知条件概率：

    \[ p(F=a|B=r)=\tfrac{1}{4}, \quad p(F=o|B=r)=\tfrac{3}{4} \]
    \[ p(F=a|B=b)=\tfrac{3}{4}, \quad p(F=o|B=b)=\tfrac{1}{4} \]

    边缘化求苹果总概率（求和规则）：

    \[ p(F=a) = p(F=a|B=r)\,p(B=r) + p(F=a|B=b)\,p(B=b) = \frac{1}{4} \cdot \frac{4}{10} + \frac{3}{4} \cdot \frac{6}{10} = \frac{11}{20} \]

    反转条件概率（贝叶斯定理）：已知取到橙子，反推来自红盒子的概率：

    \[ p(B=r \mid F=o) = \frac{p(F=o \mid B=r)\,p(B=r)}{p(F=o)} = \frac{3/4 \cdot 4/10}{9/20} = \frac{2}{3} \]

    关键解读：

    • \(p(B=r) = 4/10\)：先验（Prior），观测前的信念
    • \(p(F=o \mid B=r)\)：似然（Likelihood），数据对参数的依赖
    • \(p(B=r \mid F=o) = 2/3\)：后验（Posterior），观测后的更新信念

    观测到橙子后，红盒子的概率从 40% 上升到 67%，符合直觉（红盒子橙子比例更高）。

    独立性：若 \(p(X,Y) = p(X)\,p(Y)\)，则 \(X\) 与 \(Y\) 独立，此时 \(p(Y|X) = p(Y)\)。

    水果盒子 ↔ 深度学习：概念映射表¶

    水果盒子例子 概率角色 深度学习中的对应
    \(p(B=r) = 0.4\) 先验 Prior 模型初始化时对各类别权重的初始假设（如各类别平衡 → uniform prior）
    \(p(F=o \mid B=r)\) 似然 Likelihood 给定模型参数后，观察到某输出 label 的概率 → softmax 输出的含义
    \(p(B=r \mid F=o)\) 后验 Posterior 训练后网络对新样本输出的置信度——观察数据后更新了信念
    \(\sum_B p(F \mid B)p(B)\) 边缘化 Marginalization mixture model 中对 latent variable 求和、attention 中对所有 key 加权求和
    盒子 → 水果 生成方向 生成模型（GAN, VAE, Diffusion）: latent → observation

    上表最重要的启示：深度学习的前向传播 = 计算似然（或后验），而训练 = 贝叶斯更新。 你的网络在数据流过时的每一层输出，本质上都在做概率推断——只不过多数时候你没把这个视角挂上。

    1.2.1 概率密度（Probability Densities）¶

    对连续变量 \(x\)，若 \(x\) 落在 \((x, x+\delta x)\) 的概率为 \(p(x)\,\delta x\)（\(\delta x \to 0\)），则 \(p(x)\) 称为概率密度函数（PDF）。

    离散变量的概率概念可以扩展到连续变量 \(x\) 上的概率密度 \(p(x)\)。其含义是：当 \(\delta x \to 0\) 时，\(x\) 落在区间 \((x, x + \delta x)\) 内的概率由 \(p(x)\delta x\) 给出。概率密度可以表示为累积分布函数 \(P(x)\) 的导数。

    离散变量的 sum rule 和 product rule 同样适用于连续变量

    有效 PDF 的条件¶

    \[ p(x) \geq 0, \qquad \int_{-\infty}^{\infty} p(x)\,dx = 1 \]

    区间概率：

    \[ p(x \in (a,b)) = \int_a^b p(x)\,dx \]

    累积分布函数（CDF）：

    \[ P(z) = \int_{-\infty}^z p(x)\,dx, \qquad P'(x) = p(x) \]

    变量变换的 Jacobian¶

    若 \(x = g(y)\)，则：

    \[ p_y(y) = p_x(g(y))\left|\frac{dx}{dy}\right| = p_x(g(y))\,|g'(y)| \]

    重要：概率密度的极大值点依赖于变量的选取，不同参数化下极大值点的位置会改变。

    多变量推广¶

    对 \(D\) 维向量 \(\mathbf{x}\)：

    \[ p(\mathbf{x}) \geq 0, \qquad \int p(\mathbf{x})\,d\mathbf{x} = 1 \]

    连续变量的求和规则与乘积规则（积分代替求和）：

    \[ p(x) = \int p(x,y)\,dy, \qquad p(x,y) = p(y|x)\,p(x) \]

    🔗 变量变换公式 → Normalizing Flows 的理论基石¶

    本节最容易被跳过的 Jacobian 公式：

    \[p_y(y) = p_x(g(y))\left|\frac{dx}{dy}\right| = p_x(g(y))\,|g'(y)|\]

    实际上是 Normalizing Flows 等现代生成模型的数学根基。 整个 Flow 模型的思路就是：从一个简单分布（如标准高斯）出发，通过一系列可逆变换 \(f = f_K \circ \cdots \circ f_1\) 把样本变成一个复杂分布，而每个变换后的 log-probability 等于：

    \[\log p_K(z_K) = \log p_0(z_0) - \sum_{k=1}^K \log \left|\det \frac{\partial f_k}{\partial z_{k-1}}\right|\]

    这就是本节单个变换公式在 \(K\) 步串联后的直接推广。RealNVP、GLOW、连续归一化流（CNF）的核心创新就是"设计一个表达能力足够强、同时 Jacobian 行列式好算的可逆变换"——你在 Flow 模型代码里见到的 log_det_jacobian 函数，就是对上面这个公式的工程实现。

    VAE 的 reparameterization trick 也是特例： \(z = \mu + \sigma \odot \epsilon\)（\(\epsilon \sim \mathcal{N}(0,I)\)），这里的变换是线性的，Jacobian = \(\sigma\)，所以 log-probability 只差一个常数因子。

    1.2.2 期望与协方差¶

    期望（Expectation）¶

    函数 \(f(x)\) 在分布 \(p(x)\) 下的期望：

    \[ \mathbb{E}[f] = \sum_x p(x)\,f(x) \quad \text{（离散）}, \qquad \mathbb{E}[f] = \int p(x)\,f(x)\,dx \quad \text{（连续）} \]

    [!note] 期望公式的推理过程 期望的核心思想是“按概率加权的平均值”。若随机变量 \(x\) 可以取离散值 \(x_1, x_2, \ldots, x_M\)，并且 \(x_i\) 出现的概率为 \(p(x_i)\)，那么函数值 \(f(x_i)\) 对整体平均的贡献不应该相同，而应该由它出现的概率决定。出现越频繁的值，对平均结果的影响越大。因此：

    \[ \mathbb{E}[f] = \sum_{i=1}^{M} p(x_i)f(x_i) \]

    这个式子也可以从有限样本平均推出。假设一共有 \(N\) 个样本，其中 \(x_i\) 出现了 \(n_i\) 次，则样本平均为：

    \[ \frac{1}{N}\sum_{n=1}^{N} f(x_n) = \sum_{i=1}^{M} \frac{n_i}{N} f(x_i) \]

    当 \(N \to \infty\) 时，频率 \(\frac{n_i}{N}\) 会趋近于概率 \(p(x_i)\)，于是得到：

    \[ \mathbb{E}[f] = \sum_{i=1}^{M} p(x_i)f(x_i) \]

    对连续变量来说，单点概率通常为 \(0\)，因此不能再用求和统计每个取值，而要把变量轴切成许多很小的区间。区间 \((x, x + dx)\) 内的概率约为 \(p(x)dx\)，该区间对平均值的贡献约为 \(f(x)p(x)dx\)。把所有区间贡献相加，并令区间宽度趋于 \(0\)，就得到积分形式：

    \[ \mathbb{E}[f] = \int p(x)f(x)\,dx \]

    因此，离散情形中的“概率加权求和”，在连续情形中自然变成“概率密度加权积分”。

    有限 \(N\) 个样本的近似（Monte Carlo 估计）：

    \[ \mathbb{E}[f] \approx \frac{1}{N}\sum_{n=1}^N f(x_n), \qquad N \to \infty \text{ 时精确} \]

    🔗 你每天都在做 Monte Carlo 估计——mini-batch SGD 的本质： 训练神经网络时，真实目标是最小化整个数据分布上的期望损失 \(\mathbb{E}_{(x,y)\sim p_{\text{data}}}[\mathcal{L}(f_\theta(x), y)]\)。但你永远看不到完整分布，只能看到训练集。每一次 optimizer.step() 做的事就是：

    \[ \mathbb{E}[\nabla_\theta \mathcal{L}] \approx \frac{1}{B}\sum_{i=1}^B \nabla_\theta \mathcal{L}(f_\theta(x_i), y_i) \]

    即用 batch 内 \(B\) 个样本的样本均值来近似真实梯度期望——这就是 Monte Carlo 积分思想最频繁的工程应用。batch size \(B\) 越小，MC 估计的方差越大，梯度噪声也越大（这也是为什么小 batch size 有隐式正则化效果的根源）。

    对多变量情形，下标标记被平均的变量：\(\mathbb{E}_x[f(x,y)]\) 是对 \(x\) 求平均，结果是 \(y\) 的函数。

    条件期望：

    \[ \mathbb{E}_x[f \mid y] = \sum_x p(x \mid y)\,f(x) \]

    方差（Variance）¶

    \[ \text{var}[f] = \mathbb{E}\left[(f(x) - \mathbb{E}[f(x)])^2\right] = \mathbb{E}[f(x)^2] - \mathbb{E}[f(x)]^2 \]

    特别地，变量 \(x\) 自身的方差：

    \[ \text{var}[x] = \mathbb{E}[x^2] - \mathbb{E}[x]^2 \]

    [!note] 方差公式的推理过程 方差的出发点是度量变量围绕其均值的波动程度。若令 \(\mu = \mathbb{E}[x]\)，则 \(x - \mu\) 表示 \(x\) 相对均值的偏离量。但如果直接对偏离量求期望，会得到：

    \[ \mathbb{E}[x - \mu] = \mathbb{E}[x] - \mu = \mu - \mu = 0 \]

    也就是说，正偏离和负偏离会相互抵消，无法反映波动大小。因此需要先平方再求期望：

    \[ \text{var}[x] = \mathbb{E}[(x - \mu)^2] \]

    展开平方项：

    \[ (x - \mu)^2 = x^2 - 2\mu x + \mu^2 \]

    代入方差定义，并利用期望的线性性质：

    \[ \begin{aligned} \text{var}[x] &= \mathbb{E}[x^2 - 2\mu x + \mu^2] \\ &= \mathbb{E}[x^2] - 2\mu\mathbb{E}[x] + \mathbb{E}[\mu^2] \end{aligned} \]

    因为 \(\mu\) 是常数，所以 \(\mathbb{E}[\mu^2] = \mu^2\)；又因为 \(\mathbb{E}[x] = \mu\)，所以：

    \[ \begin{aligned} \text{var}[x] &= \mathbb{E}[x^2] - 2\mu^2 + \mu^2 \\ &= \mathbb{E}[x^2] - \mu^2 \\ &= \mathbb{E}[x^2] - \mathbb{E}[x]^2 \end{aligned} \]

    因此，方差可以理解为“平方的期望减去期望的平方”，也可以看作变量与自身的协方差：\(\text{var}[x] = \text{cov}[x,x]\)。

    协方差（Covariance）¶

    \[ \text{cov}[x,y] = \mathbb{E}_{x,y}[\{x - \mathbb{E}[x]\}\{y - \mathbb{E}[y]\}] = \mathbb{E}_{x,y}[xy] - \mathbb{E}[x]\,\mathbb{E}[y] \]

    [!note] 协方差公式的推理过程 协方差的出发点是度量两个变量相对各自均值的共同偏离程度。若令 \(\mu_x = \mathbb{E}[x]\)，\(\mu_y = \mathbb{E}[y]\)，则 \(x - \mu_x\) 表示 \(x\) 偏离均值的程度，\(y - \mu_y\) 表示 \(y\) 偏离均值的程度。二者的乘积如果经常为正，说明两个变量倾向于同向变化；如果经常为负，说明它们倾向于反向变化。因此定义：

    \[ \text{cov}[x,y] = \mathbb{E}_{x,y}[(x - \mu_x)(y - \mu_y)] \]

    展开括号可得：

    \[ \begin{aligned} \text{cov}[x,y] &= \mathbb{E}_{x,y}[xy - x\mu_y - y\mu_x + \mu_x\mu_y] \\ &= \mathbb{E}_{x,y}[xy] - \mu_y\mathbb{E}[x] - \mu_x\mathbb{E}[y] + \mu_x\mu_y \end{aligned} \]

    又因为 \(\mathbb{E}[x] = \mu_x\)，\(\mathbb{E}[y] = \mu_y\)，所以：

    \[ \begin{aligned} \text{cov}[x,y] &= \mathbb{E}_{x,y}[xy] - \mu_x\mu_y - \mu_x\mu_y + \mu_x\mu_y \\ &= \mathbb{E}_{x,y}[xy] - \mu_x\mu_y \\ &= \mathbb{E}_{x,y}[xy] - \mathbb{E}[x]\mathbb{E}[y] \end{aligned} \]

    因此，协方差既可以写成“中心化后乘积的期望”，也可以写成“乘积的期望减去期望的乘积”。当 \(x = y\) 时，协方差退化为方差：\(\text{cov}[x,x] = \text{var}[x]\)。

    若 \(x, y\) 独立，则 \(\text{cov}[x,y] = 0\)。

    对向量 \(\mathbf{x}\) 和 \(\mathbf{y}\)，协方差是矩阵：

    \[ \text{cov}[\mathbf{x},\mathbf{y}] = \mathbb{E}_{\mathbf{x},\mathbf{y}}\left[\{\mathbf{x} - \mathbb{E}[\mathbf{x}]\}\{\mathbf{y}^T - \mathbb{E}[\mathbf{y}^T]\}\right] = \mathbb{E}[\mathbf{x}\mathbf{y}^T] - \mathbb{E}[\mathbf{x}]\,\mathbb{E}[\mathbf{y}^T] \]

    简写 \(\text{cov}[\mathbf{x}] \equiv \text{cov}[\mathbf{x},\mathbf{x}]\)。

    🔗 协方差矩阵在深度学习中的三个关键出场¶

    1. Batch Normalization (BN)： BN 的 forward pass 本质上是用 mini-batch 估计每个特征的均值和方差（协方差矩阵的对角线）： $\(\hat{x} = \frac{x - \mathbb{E}_{\text{batch}}[x]}{\sqrt{\text{var}_{\text{batch}}[x] + \epsilon}}\)$ 训练时用 batch 统计量，测试时用 running average。这本质上是"运行时协方差（对角线）估计"。

    2. 数据预处理中的 PCA 白化： 对数据矩阵的协方差矩阵做特征分解 \(\Sigma = U\Lambda U^T\)，然后用 \(\Lambda^{-1/2}U^T\) 变换数据，使得变换后的各维度去相关且方差为 1。这是训练深层网络前对输入做标准化的统计理由。

    3. Mahalanobis 距离： \(d_M(x, \mu) = \sqrt{(x-\mu)^T \Sigma^{-1}(x-\mu)}\)，用协方差矩阵做"方向性缩放"——在方差大的方向上允许更大偏离，在方差小的方向上更严格要求接近均值。欧氏距离 \(= \Sigma = I\) 的特例（假设各维度独立且等方差，大多数时候并非如此）。这在异常检测和 few-shot classification（如 Prototypical Networks with Mahalanobis distance）中有直接应用。

    1.2.3 贝叶斯概率（Bayesian Probabilities）¶

    频率派 vs 贝叶斯派¶

    视角 概率的含义 参数的状态 不确定性来源
    频率派（Frequentist） 可重复事件的长期频率 固定未知常数 数据的随机性
    贝叶斯派（Bayesian） 对不确定性的量化信念 随机变量，有分布 对参数知识的缺乏

    贝叶斯的优势：可以处理不可重复事件（如"北极冰盖在本世纪消失的概率"），也可以自然地引入先验知识。Cox (1946) 证明：若用数值表示信念度且满足一组常识公理，则这些数值必须服从概率论的规则。

    贝叶斯定理在参数推断中的角色¶

    以多项式曲线拟合为例，参数 \(\mathbf{w}\) 是未知量：

    \[ p(\mathbf{w} \mid \mathcal{D}) = \frac{p(\mathcal{D} \mid \mathbf{w})\, p(\mathbf{w})}{p(\mathcal{D})} \]

    \(p(\mathcal{D})\) 是归一化常数，它确保左侧的后验分布是一个有效的概率密度函数，且积分为1。对两边关于 \(w\) 进行积分，我们可以将贝叶斯定理中的分母用先验分布和似然函数表示。

    \[ p(\mathcal{D}) = \int p(\mathcal{D}\mid \mathbf{w})\, p(\mathbf{w}) \, d\mathbf{w} \]
    符号 名称 含义
    \(p(\mathbf{w})\) 先验（Prior） 观测数据前对参数的信念
    \(p(\mathcal{D} \mid \mathbf{w})\) 似然（Likelihood） 给定参数时数据出现的概率，视为 \(\mathbf{w}\) 的函数
    \(p(\mathbf{w} \mid \mathcal{D})\) 后验（Posterior） 观测数据后对参数的更新信念
    \(p(\mathcal{D})\) 证据（Evidence） 归一化常数，\(= \int p(\mathcal{D}\mid\mathbf{w})\,p(\mathbf{w})\,d\mathbf{w}\)

    需要注意，似然函数不是 w 的概率分布，且其对 w 的积分（不一定）等于一。

    用语言表达：

    \[ \text{后验} \propto \text{似然} \times \text{先验} \]

    在频率主义框架下，\(w\) 被视为一个固定参数，其值由某种“估计量”确定，而该估计的误差条则通过考虑可能数据集 \(D\) 的分布来获得。相比之下，从贝叶斯观点来看，只有一个数据集 \(D\)（即实际观测到的那个），而参数的不确定性则通过 \(w\) 的概率分布来表达。

    频率派的 MLE 与 Bootstrap¶

    最大似然估计（MLE）：选使 \(p(\mathcal{D}|\mathbf{w})\) 最大的 \(\mathbf{w}\)。

    • 负对数似然 = 误差函数（error function）
    • 最大化似然 ↔ 最小化误差

    在机器学习文献中，似然函数的负对数被称为误差函数。由于负对数是单调递减函数，最大化似然等价于最小化误差。

    🔗 似然假设 → 损失函数的完整对照表：

    你的深度网络最后那个 loss function 不是随便选的——它是你对输出变量做了某种概率假设之后，取负对数似然的自然结果：

    | 任务 | 似然假设（输出分布） | 损失函数形式 | PyTorch 实现 | | :------------- | :------------------------------------------------------ | :--------------------------------------------------- | :------------------------------------ | ------- | ----------- | | 回归（连续值） | 高斯 \(\mathcal{N}(t \mid y(x,w), \beta^{-1})\) | \(\frac{1}{2}\sum(y_n - t_n)^2\) (MSE) | nn.MSELoss | | 二分类 | 伯努利 \(\text{Bern}(t \mid \sigma(a))\) | \(-\sum[t_n\log\hat{y}_n + (1-t_n)\log(1-\hat{y}_n)]\) | nn.BCELoss / nn.BCEWithLogitsLoss | | 多分类 | 类别/Categorical \(\text{Cat}(t \mid \text{softmax}(a))\) | \(-\sum\sum t_{nk}\log\hat{y}_{nk}\) | nn.CrossEntropyLoss | | 计数预测 | 泊松 \(\text{Poisson}(t \mid \lambda)\) | \(\sum(\lambda - t\log\lambda)\) | nn.PoissonNLLLoss | | 有序回归 | 拉普拉斯 \(\text{Laplace}(t \mid \mu, b)\) | $\sum | y_n - t_n | $ (MAE) | nn.L1Loss | | 混合建模 | Huber 折中 | 残差小用 MSE，残差大用 MAE | nn.SmoothL1Loss / nn.HuberLoss |

    核心启示：选 loss 函数 = 选概率假设。 你选 MSE 的那一刻，你已经默认了"输出服从高斯分布、且噪声方差在各数据点上是恒定的"。如果这个假设不成立（比如数据有 heavy tail），你的 loss 需要换成对应的分布假设。Loss function design is likelihood design.

    Bootstrap（One approach to determining frequentist error bars is the bootstrap (Efron, 1979; Hastie et al., 2001)）：从 \(N\) 个原始样本==有放回抽样== \(N\) 次，重复 \(L\) 次生成 \(L\) 个数据集，用预测在不同 bootstrap 数据集上的差异评估统计误差。

    🔗 Bootstrap → Deep Ensembles： Bootstrap 的核心思路是"通过重采样构造多个版本的数据集，在不同数据集上训练同一模型，用模型间的差异估计不确定性"。这和 Deep Ensembles（用不同随机种子/初始化训练多个网络，在推理时取均值 + 方差）共享同一个哲学——虽然 Deep Ensembles 不是严格意义上的 Bootstrap（没有重采样数据），但它同样通过"多个模型之间的分歧"来获得预测不确定性的估计。两者都属于频率派视角下的不确定性量化方法。

    频率派的问题：硬币连投 3 次全正面，传统 MLE 估计正面概率为 1，结论极端；贝叶斯方法加入合理先验后会给出更合理的结论。

    尽管贝叶斯框架起源于18世纪，但贝叶斯方法的实际应用长期以来受到严重限制，原因在于难以执行完整的贝叶斯过程，特别是需要对整个参数空间进行边缘化（求和或积分）——正如我们将看到的，这是进行预测或比较不同模型所必需的。采样方法（如第11章讨论的马尔可夫链蒙特卡洛）的发展，以及计算机速度和内存容量的显著提升，为贝叶斯技术在众多问题领域的实际应用打开了大门。蒙特卡洛方法非常灵活，可应用于多种模型，然而它们计算密集，主要被用于小规模问题。

    🔗 贝叶斯方法在现代深度学习中的近似实现： 虽然严格贝叶斯推理在百万参数级的网络上仍然不可行，但已有多种近似方法在深度学习中被广泛使用：

    • MC Dropout（Gal & Ghahramani, 2016）：在测试时保持 dropout 开启，多次前向传播得到一组预测样本，用其均值和方差作为预测分布——这被证明等价于对深度高斯过程做变分推断。
    • Deep Ensembles（Lakshminarayanan et al., 2017）：用不同随机初始化训练多个网络，预测时取均值（集成预测）和方差（模型不确定性）。虽然不严格等价于贝叶斯后验采样，但实践效果优异。
    • Laplace 近似 / SWAG：在训练好的网络权重上，用 loss landscape 的二阶信息（Hessian 或经验 Fisher）构造一个局部高斯近似后验。SWAG（Stochastic Weight Averaging-Gaussian）进一步通过 SGD 轨迹的统计量来近似后验协方差。
    • Variational Inference (VI) / Bayes by Backprop：直接在训练中优化一个近似后验 \(q_\phi(w)\)，用 KL 散度约束它不要离先验太远。

    所有这些方法的共同目标就是 §1.2.6 要揭示的核心思想：不只输出点预测，还要输出预测的不确定性。

    1.2.4 高斯分布（The Gaussian Distribution）¶

    一元高斯¶

    \[ \mathcal{N}(x \mid \mu, \sigma^2) = \frac{1}{(2\pi\sigma^2)^{1/2}} \exp\!\left(-\frac{(x-\mu)^2}{2\sigma^2}\right) \]

    参数：

    • \(\mu\)：均值（mean），即分布的期望 \(\mathbb{E}[x] = \mu\)
    • \(\sigma^2\)：方差（variance），\(\text{var}[x] = \sigma^2\)
    • \(\sigma\)：标准差（standard deviation）
    • \(\beta = 1/\sigma^2\)：精度（precision）
    \[ \mathbb{E}[x] = \int_{-\infty}^{\infty} \mathcal{N}(x \mid \mu,\sigma^2)\, x \, dx = \mu \]
    \[ \mathbb{E}[x^2] = \int_{-\infty}^{\infty} \mathcal{N}(x \mid \mu,\sigma^2)\, x^2 \, dx = \mu^2+\sigma^2 \]
    \[ \operatorname{var}[x] = \mathbb{E}[x^2] - \mathbb{E}[x]^2 = \sigma^2 \]

    单变量高斯分布的图，显示了均值 \(μ\) 和标准差 \(σ\) 。

    性质：\(\mathcal{N}(x|\mu,\sigma^2) > 0\)，\(\int_{-\infty}^{\infty}\mathcal{N}(x|\mu,\sigma^2)\,dx = 1\)，众数（mode）= 均值 \(\mu\)。

    🔗 为什么高斯分布在深度学习中无处不在？ 两个根本原因：

    1. 中心极限定理（CLT）： 大量独立随机变量的和趋于高斯分布。神经网络的权重梯度是大量样本梯度的和 → 梯度噪声近似高斯；参数初始化（Gaussian/truncated normal）利用了这一点；SGD 噪声也可以近似建模为高斯扰动。
    2. 最大熵性质： 在所有具有给定均值 \(\mu\) 和方差 \(\sigma^2\) 的一维分布中，高斯分布具有最大熵。这意味着：当你只知道均值和方差、不知道其他任何信息时，选择高斯分布是"最不武断的"（makes the fewest extra assumptions）——这是信息论视角下的自然选择。

    关于精度 \(\beta = 1/\sigma^2\)：为什么 PRML 全书用精度而非方差？ 这是一个重要的符号选择。用精度表示时，高斯分布的指数部分写作 \(-\frac{\beta}{2}(x-\mu)^2\) 而非 \(-\frac{1}{2\sigma^2}(x-\mu)^2\)，形式更简洁。更重要的是，精度在贝叶斯更新中有自然的可加性：如果多个独立的高斯似然相乘，其精度会自然相加；在共轭先验的更新中，后验精度 = 先验精度 + 数据精度 × 样本数。这对于理解 §1.2.5 的 \(\lambda = \alpha/\beta\)（先验精度与噪声精度之比）至关重要。

    多元高斯¶

    \[ \mathcal{N}(\mathbf{x} \mid \boldsymbol{\mu}, \boldsymbol{\Sigma}) = \frac{1}{(2\pi)^{D/2}|\boldsymbol{\Sigma}|^{1/2}} \exp\!\left(-\frac{1}{2}(\mathbf{x}-\boldsymbol{\mu})^T \boldsymbol{\Sigma}^{-1}(\mathbf{x}-\boldsymbol{\mu})\right) \]
    • \(\boldsymbol{\mu}\)：\(D\) 维均值向量
    • \(\boldsymbol{\Sigma}\)：\(D \times D\) 协方差矩阵

    高斯分布的似然函数示意图（如红色曲线所示）。其中黑色点表示数据集 \({x_n}\) 中的值，由公式 \(p(\mathbf{x} \mid \mu, \sigma^2) = \prod_{n=1}^N \mathcal{N}(x_n \mid \mu, \sigma^2)\) 给出的似然函数对应于蓝色数值的乘积。最大化似然涉及调整高斯分布的均值与方差，从而使其乘积最大化。

    MLE 估计高斯参数¶

    给定 i.i.d. 数据 \(\mathbf{x} = (x_1,\ldots,x_N)^T\)，似然为：

    \[ p(\mathbf{x} \mid \mu, \sigma^2) = \prod_{n=1}^N \mathcal{N}(x_n \mid \mu, \sigma^2) \]

    对数似然：

    \[ \ln p(\mathbf{x} \mid \mu, \sigma^2) = -\frac{1}{2\sigma^2}\sum_{n=1}^N (x_n - \mu)^2 - \frac{N}{2}\ln\sigma^2 - \frac{N}{2}\ln(2\pi) \]

    MLE 解析解：

    \[ \mu_{\text{ML}} = \frac{1}{N}\sum_{n=1}^N x_n \quad \text{（样本均值）} \]
    \[ \sigma^2_{\text{ML}} = \frac{1}{N}\sum_{n=1}^N (x_n - \mu_{\text{ML}})^2 \quad \text{（样本方差）} \]

    MLE 方差的偏差（Bias）¶

    \[ \mathbb{E}[\mu_{\text{ML}}] = \mu \quad \text{（无偏）} \]
    \[ \mathbb{E}[\sigma^2_{\text{ML}}] = \frac{N-1}{N}\sigma^2 \quad \text{（有偏，系统性低估）} \]

    无偏方差估计：

    \[ \tilde{\sigma}^2 = \frac{N}{N-1}\sigma^2_{\text{ML}} = \frac{1}{N-1}\sum_{n=1}^N(x_n - \mu_{\text{ML}})^2 \]

    直觉：样本方差是相对于样本均值而非真实均值度量的，而样本均值本身已经"偷走"了一个自由度。分母用 \(N-1\) 而非 \(N\) 即 Bessel 校正。

    深层联系：MLE 方差偏低 ↔ 高斯分布参数估计的过拟合 ↔ 1.1 节多项式拟合过拟合，本质上都是最大似然在复杂模型下的系统性问题。

    概率建模¶

    假设观测目标值 \(t\) 由多项式 \(y(x, \mathbf{w})\) 加高斯噪声生成：

    \[ p(t \mid x, \mathbf{w}, \beta) = \mathcal{N}(t \mid y(x,\mathbf{w}),\, \beta^{-1}) \]

    其中 \(\beta = 1/\sigma^2\) 是精度参数。

    最大似然 → 最小二乘¶

    训练集的似然（i.i.d. 假设）：

    \[ p(\mathbf{t} \mid \mathbf{x}, \mathbf{w}, \beta) = \prod_{n=1}^N \mathcal{N}(t_n \mid y(x_n,\mathbf{w}),\, \beta^{-1}) \]

    对数似然：

    \[ \ln p(\mathbf{t} \mid \mathbf{x}, \mathbf{w}, \beta) = -\frac{\beta}{2}\sum_{n=1}^N \{y(x_n,\mathbf{w}) - t_n\}^2 + \frac{N}{2}\ln\beta - \frac{N}{2}\ln(2\pi) \]

    最大化对 \(\mathbf{w}\) 的对数似然 ≡ 最小化平方和误差 \(E(\mathbf{w})\)。

    结论：平方误差函数是高斯噪声假设下最大似然的自然结果，而非人为规定。

    🔗 选 loss 函数 = 选噪声分布假设：

    • 如果假设噪声是高斯 → 最大化似然 = 最小化 MSE → nn.MSELoss
    • 如果假设噪声是拉普拉斯 → 最大化似然 = 最小化 MAE → nn.L1Loss
    • Huber Loss / Smooth L1 Loss 存在的理由：在高斯和拉普拉斯之间折中——残差小的时候用 MSE（平滑可导），残差大的时候用 MAE（对异常值鲁棒），等价于在分布的中心用高斯、尾部用拉普拉斯。

    因此，当你下次纠结"回归任务用什么 loss"时，真正的思考应该是："我认为预测误差服从什么分布？"——这是个建模问题，不是调参问题。

    对 \(\beta\) 最大化得到精度估计：

    \[ \frac{1}{\beta_{\text{ML}}} = \frac{1}{N}\sum_{n=1}^N\{y(x_n, \mathbf{w}_{\text{ML}}) - t_n\}^2 \]

    预测分布¶

    将 MLE 参数代入概率模型，得到对新 \(x\) 的预测分布（Predictive Distribution）：

    \[ p(t \mid x, \mathbf{w}_{\text{ML}}, \beta_{\text{ML}}) = \mathcal{N}(t \mid y(x,\mathbf{w}_{\text{ML}}),\, \beta_{\text{ML}}^{-1}) \]

    这给出的不只是一个点估计，而是一个完整的概率分布，包含了预测的不确定性。

    MAP → 正则化¶

    在 \(\mathbf{w}\) 上加高斯先验：

    \[ p(\mathbf{w} \mid \alpha) = \mathcal{N}(\mathbf{w} \mid \mathbf{0},\, \alpha^{-1}\mathbf{I}) \]

    后验正比于：

    \[ p(\mathbf{w} \mid \mathbf{x}, \mathbf{t}, \alpha, \beta) \propto p(\mathbf{t} \mid \mathbf{x}, \mathbf{w}, \beta)\, p(\mathbf{w} \mid \alpha) \]

    最大化后验（MAP）等价于最小化正则化误差：

    \[ \frac{\beta}{2}\sum_{n=1}^N\{y(x_n,\mathbf{w})-t_n\}^2 + \frac{\alpha}{2}\mathbf{w}^T\mathbf{w} \]

    关键等式：\(\lambda = \alpha/\beta\)，正则化强度 = 先验精度 / 噪声精度。这从概率角度解释了 1.1 节中 \(\lambda\) 的来源。

    🔗 \(\lambda = \alpha/\beta\) 的深层直觉——你的 weight_decay 到底在做什么：

    这个等式告诉你，正则化强度并非一个"独立"的超参数，而是你对先验的信心（\(\alpha\)）与你对数据的信心（\(\beta\)）之比：

    场景 α（先验精度） β（数据精度/噪声倒数） λ = α/β 含义
    数据噪声大 不变 ↓（β 小） ↑ 大 数据不可靠 → 自动更多信任先验 → 加强正则化
    数据很干净 不变 ↑（β 大） ↓ 小 数据可靠 → 更多地拟合数据 → 减弱正则化
    强信念权重接近 0 ↑（α 大） 不变 ↑ 大 你确信模型应该简单 → 强正则化
    弱信念/无先验 ↓（α 小） 不变 ↓ 小 让数据说话 → 弱正则化 → 趋近 MLE

    这解释了为什么噪声标签（noisy labels）的数据集上应该用更大的 weight_decay——因为 \(\beta\)（数据精度）降低了，\(\lambda\) 自动应该增大。也解释了为什么数据量越大，正则化需求越小——更多数据等价于更大的有效精度。

    1.2.6 贝叶斯曲线拟合（Bayesian Curve Fitting）¶

    MAP 仍然是对 \(\mathbf{w}\) 的点估计，不算完整的贝叶斯处理。

    完整的贝叶斯方法要对所有 \(\mathbf{w}\) 积分（边缘化）：

    \[ p(t \mid x, \mathbf{x}, \mathbf{t}) = \int p(t \mid x, \mathbf{w})\, p(\mathbf{w} \mid \mathbf{x}, \mathbf{t})\, d\mathbf{w} \]

    其中 \(p(\mathbf{w} \mid \mathbf{x}, \mathbf{t})\) 是 \(\mathbf{w}\) 的后验分布（由贝叶斯定理从先验和似然计算）。

    由于先验和似然都是高斯，后验也是高斯，预测分布也是高斯，具有解析解：

    \[ p(t \mid x, \mathbf{x}, \mathbf{t}) = \mathcal{N}(t \mid m(x),\, s^2(x)) \]

    其中均值 \(m(x)\) 和方差 \(s^2(x)\) 都是 \(x\) 的函数（具体形式见第 3.3 节）。

    贝叶斯 vs MLE 的核心差异：

    • MLE/MAP：单个最优 \(\mathbf{w}\)，预测方差仅来自噪声 \(\beta^{-1}\)
    • 贝叶斯：对所有 \(\mathbf{w}\) 积分，预测方差 = 噪声方差 + 模型参数不确定性

    贝叶斯方法的预测不确定性在数据稀少处更大，在数据密集处更小，这更符合物理直觉。

    🔗 Aleatoric vs Epistemic 不确定性——现代深度学习中的关键区分¶

    完整贝叶斯预测的两个方差来源，对应现代深度学习中最重要的一对不确定性概念：

    \[ \underbrace{s^2(x)}_{\text{总预测方差}} = \underbrace{\beta^{-1}}_{\text{噪声方差}} + \underbrace{\text{模型参数不确定性}}_{\text{后验方差} \to s^2(x)\text{的一部分}} \]
    不确定性类型 来源 能否通过更多数据消除？ 深度学习中如何处理？
    偶然不确定性 Aleatoric 数据本身的噪声（\(\beta^{-1}\)） ❌ 不能——数据生成过程本身的随机性 网络输出两个 head：均值 + 方差（heteroscedastic loss）
    认知不确定性 Epistemic 模型参数的知识不足（后验宽度） ✅ 能——更多数据 → 后验变窄 → 不确定性减小 MC Dropout / Deep Ensembles / Bayesian NN

    为什么这个区分在 safety-critical 应用中至关重要：

    • 自动驾驶遇到暴雨（aleatoric）：传感器噪声大但模型"知道路怎么走" → 可以继续行驶但更加谨慎
    • 自动驾驶在从未见过的山路上（epistemic）：模型不知道该做什么 → 应该减速/请求人类接管
    • 医学影像 AI 在训练集覆盖良好的病变类型上（low epistemic）→ 可以信任诊断
    • 在来源医院的新设备拍摄的影像上（high epistemic）→ 必须标记"不确定性高，需医生复核"

    如果不区分这两种不确定性，系统要么对所有情况都过于自信（危险），要么对所有情况都犹豫不决（无用）。

def map_curve_fitting(x, t, M, alpha, beta_noise):
    """MAP 估计：后验 ∝ 似然 × 先验"""
    Phi = design_matrix(x, M)
    # w* = (βΦᵀΦ + αI)⁻¹ βΦᵀt

    return np.linalg.solve(A, b)

    import torch
import torch.nn as nn

# ── 验证变量变换公式：p_y(y) = p_x(g(y)) |g'(y)| ─────────────────
# 使用一个简单的 Planar Flow 变换来观察概率密度的变化

def planar_flow(z, u, w, b):
    """
    Planar Flow: z' = z + u · tanh(wᵀz + b)
    参考文献: Rezende & Mohamed (ICML 2015)
    """
    dot = torch.matmul(z, w.unsqueeze(1)) + b  # shape: (N, 1)
    return z + u * torch.tanh(dot)

def log_det_jacobian_planar(z, u, w, b):
    """
    log |det ∂f/∂z| = log |det(I + u ψ'(z) wᵀ)|
    对于 rank-1 更新，det(I + u vᵀ) = 1 + uᵀv
    """
    dot = torch.matmul(z, w.unsqueeze(1)) + b  # (N, 1)
    psi_prime = 1 - torch.tanh(dot) ** 2          # sech² = tanh'
    # det(I + u ψ' wᵀ) = 1 + u·w · ψ'
    det = 1 + torch.matmul(psi_prime * w, u)     # (N,)
    return torch.log(torch.abs(det) + 1e-12)

# 参数设置
torch.manual_seed(42)
u = torch.tensor([1.0, -0.5])
w = torch.tensor([0.8, 0.6])
b = torch.tensor(0.3)

# 从标准高斯采样
z0 = torch.randn(5000, 2)  # p_z(z) = 𝒩(0, I)

# 用标准方法计算：log p(z) = -0.5 * (2*log(2π) + zᵀz)

# 应用 Flow 变换

    推导树（ASCII）¶

    离散概率
├── 联合概率 p(X,Y) = n_ij / N
├── 求和规则: p(X) = Σ_Y p(X,Y)         ← 边缘化
├── 乘积规则: p(X,Y) = p(Y|X)·p(X)      ← 条件化
└── 贝叶斯定理: p(Y|X) = p(X|Y)p(Y)/p(X)

连续概率
├── PDF: p(x)≥0, ∫p(x)dx=1
├── CDF: P(z) = ∫_{-∞}^z p(x)dx
├── 变量变换: py(y) = px(g(y))|g'(y)|  ← Jacobian
└── 求和/乘积规则：积分代替求和

期望 E[f] = Σ p(x)f(x)  或  ∫p(x)f(x)dx
方差 var[x] = E[x²] - E[x]²
协方差 cov[x,y] = E[xy] - E[x]E[y]

频率派 vs 贝叶斯
├── MLE: max p(D|w) → 点估计 w_ML
├── MAP: max p(w|D) ∝ p(D|w)p(w) → 点估计 w_MAP = 正则化
└── 完整贝叶斯: ∫p(t|x,w)p(w|D)dw → 预测分布，含参数不确定性

MLE 的偏差: E[σ²_ML] = (N-1)/N · σ² → 过拟合的概率根源
λ = α/β: 正则化强度 = 先验精度 / 噪声精度

    本节核心：概率论不仅是计算工具，更是描述不确定性的统一语言。贝叶斯定理将先验知识（Prior）与新观测数据（Likelihood）融合，给出后验（Posterior），这一框架贯穿全书。1.2.5 节揭示了最小二乘和正则化的概率起源，为后续贝叶斯线性回归（第 3 章）打下基础。
